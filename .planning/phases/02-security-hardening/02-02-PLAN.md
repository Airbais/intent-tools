from flask import jsonify
from pydantic import ValidationError
from werkzeug.exceptions import HTTPException

**Logger:**
```python
logger = logging.getLogger(__name__)
```

**Error handler functions:**

1. `handle_validation_error(e: ValidationError)`:
   - Log: `logger.warning(f"Validation error: {e.errors()}")`
   - Return: `jsonify({'error': 'Invalid request parameters', 'details': e.errors()}), 400`
   - Pydantic v2 errors are safe to expose (no file paths, just field names and messages)

2. `handle_bad_request(e)`:
   - Log: `logger.warning(f"Bad request: {e}")`
   - Return: `jsonify({'error': 'Bad request', 'message': str(e.description) if hasattr(e, 'description') else 'Invalid request'}), 400`

3. `handle_not_found(e)`:
   - No logging needed (expected behavior)
   - Return: `jsonify({'error': 'Not found', 'message': 'The requested resource does not exist'}), 404`

4. `handle_internal_error(e)`:
   - Log: `logger.error(f"Internal server error: {str(e)}", exc_info=True)` (CRITICAL: exc_info=True for traceback in logs)
   - Return: `jsonify({'error': 'Internal server error', 'message': 'An unexpected error occurred. Please try again later.'}), 500`
   - NEVER include str(e) in response - could contain file paths, SQL queries, etc.

5. `handle_unexpected_exception(e)`:
   - Log: `logger.critical(f"Unhandled exception: {type(e).__name__}: {str(e)}", exc_info=True)`
   - Return: `jsonify({'error': 'Internal server error', 'message': 'An unexpected error occurred'}), 500`

**Registration function:**
```python
def register_error_handlers(app):
    """Register all error handlers with Flask app."""
    app.register_error_handler(ValidationError, handle_validation_error)
    app.register_error_handler(400, handle_bad_request)
    app.register_error_handler(404, handle_not_found)
    app.register_error_handler(500, handle_internal_error)
    app.register_error_handler(Exception, handle_unexpected_exception)
```

Include module docstring explaining purpose: sanitize errors for clients while preserving debug info in logs.
