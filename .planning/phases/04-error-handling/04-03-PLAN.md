  <action>
Fix two exception handling issues:

**1. Replace bare except at line 203 (dashboard metrics parsing):**

Current code:
```python
except:
    pass
```

Replace with:
```python
except (json.JSONDecodeError, KeyError, IOError) as e:
    # Dashboard metrics are optional - log and continue
    logger.debug(
        "dashboard_metrics_parse_failed",
        file_path=file_path,
        error=str(e),
        exc_info=True
    )
```

Why these exceptions:
- json.JSONDecodeError: Malformed JSON
- KeyError: Missing expected keys (shouldn't happen with .get() but defensive)
- IOError: File read issues

**2. Fix config loading (around line 43):**

Current code:
```python
except Exception as e:
    logger.error("config_load_failed", ...)
```

Replace `Exception` with specific types:
```python
except (yaml.YAMLError, IOError) as e:
    logger.error("config_load_failed", config_path=config_path, error=str(e), exc_info=True)
    return {'tools': {}, 'server': {'port': 8888, 'host': '0.0.0.0'}}
```

Add yaml.YAMLError to handle malformed YAML specifically.

Note: Keep the fallback dict return - config errors should allow server to start with defaults.
