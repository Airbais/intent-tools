<task type="auto">
  <name>Task 1: Create custom exception hierarchy</name>
  <files>automation/exceptions.py</files>
  <action>
Create `automation/exceptions.py` with a custom exception hierarchy:

1. **Base class: AirbaisAPIException**
   - Inherits from Exception
   - Constructor accepts: message (str), error_code (str), status_code (int, default 500)
   - Stores all three as instance attributes
   - Provides __str__ returning message

2. **Domain exceptions:**
   - `ToolNotFoundError(tool_name: str)` - 404, TOOL_NOT_FOUND
   - `ToolExecutionError(tool_name: str, details: str)` - 500, TOOL_EXECUTION_FAILED
   - `JobNotFoundError(job_id: str)` - 404, JOB_NOT_FOUND
   - `ConfigurationError(details: str)` - 500, CONFIG_ERROR
   - `InvalidParameterError(param_name: str, reason: str)` - 400, INVALID_PARAMETER

Each domain exception should:
- Call super().__init__ with appropriate message, error_code, status_code
- Store domain-specific attributes (e.g., tool_name, job_id)

Example message formats:
- ToolNotFoundError: "Tool 'intentcrawler' not found"
- JobNotFoundError: "Job 'abc-123' not found"
- ToolExecutionError: "Tool execution failed: {details}"

Include module docstring explaining the hierarchy and usage pattern.
  </action>
  <verify>
python -c "from automation.exceptions import AirbaisAPIException, ToolNotFoundError, ToolExecutionError, JobNotFoundError, ConfigurationError, InvalidParameterError; e = ToolNotFoundError('test'); print(f'{e.error_code}, {e.status_code}, {e}')"

Expected output: TOOL_NOT_FOUND, 404, Tool 'test' not found
  </verify>
  <done>
All custom exception classes importable with correct error_code and status_code attributes.
  </done>

Create `automation/utils.py` with UTC-aware datetime utilities:

1. **utc_now_iso() -> str**
   - Returns current UTC time as ISO 8601 / RFC 3339 string
   - Uses `datetime.now(timezone.utc).isoformat()`
   - Output format: "2026-01-24T12:34:56.789123+00:00"

2. **utc_now() -> datetime**
   - Returns current UTC time as timezone-aware datetime object
   - Useful when datetime object needed (not just string)

Import from datetime module: `from datetime import datetime, timezone`

Include docstrings explaining:
- Why UTC (consistent across timezones, log aggregation)
- Why .isoformat() not strftime (RFC 3339 compliance)
- Why timezone.utc not utcnow() (deprecated in Python 3.12)

Module docstring should reference ERR-05 requirement.
  </action>
