   ```python
   def handle_airbais_exception(e: AirbaisAPIException):
       """
       Handle custom Airbais API exceptions.

       Logs error with context and returns structured response using
       the exception's error_code and status_code attributes.
       """
       logger.error(
           "airbais_api_error",
           error_code=e.error_code,
           status_code=e.status_code,
           error=str(e),
           exc_info=True
       )
       return build_error_response(
           error=type(e).__name__,
           message=e.message,
           status_code=e.status_code,
           error_code=e.error_code
       )
   ```

3. Update register_error_handlers() to include the new handler:
   - Add `app.register_error_handler(AirbaisAPIException, handle_airbais_exception)`
