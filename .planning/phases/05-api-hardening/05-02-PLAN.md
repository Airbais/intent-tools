3. Create automation/health/readiness.py:
   ```python
   """
   Readiness check: Can we accept traffic?

   Check dependencies but use SHORT timeouts.
   Kubernetes will REMOVE from load balancer if this fails (no restart).
   """
   import structlog

   logger = structlog.get_logger(__name__)


   def check():
       """Readiness check - verify server can accept requests.

       Currently checks:
       - Basic server responsiveness (if we get here, Flask is running)

       Future checks could include:
       - Rate limit storage connection (Redis when configured)
       - Tool configuration loaded
       - Results directory writable

       Returns:
           dict: Status information with component health

       Raises:
           Exception: If any critical dependency is unavailable
       """
       status = {
           "status": "ready",
           "checks": {}
       }

       # Check 1: Configuration loaded
       try:
           from api_server import TOOL_CONFIGS
           status["checks"]["config"] = {
               "status": "ok",
               "tools_loaded": len(TOOL_CONFIGS)
           }
       except ImportError as e:
           logger.warning("readiness_check_failed", component="config", error=str(e))
           status["checks"]["config"] = {"status": "degraded", "error": str(e)}

       return status
   ```

3. Add rate limit decorators to endpoints:

   - /<tool_name>/analyze (POST): Strict limit - expensive operation
     ```python
     @app.route('/<tool_name>/analyze', methods=['POST'])

     ```

   - /status/<job_id> (GET): Lenient - frequent polling expected
     ```python

     ```

   - /results/<job_id> (GET): Moderate - results retrieval
     ```python
     @app.route('/results/<job_id>', methods=['GET'])
     @limiter.limit("60 per minute")
     def get_results(job_id):
     ```

   - /jobs (GET): Moderate - job listing
     ```python
     @app.route('/jobs', methods=['GET'])
     @limiter.limit("30 per minute")
     def list_jobs():
     ```

4. Add new health check endpoints with rate limit exemption:
   ```python
   @app.route('/health/live', methods=['GET'])
   @limiter.exempt
   def health_live():
       """Kubernetes liveness probe - is process alive?"""
       result = liveness_check()
       return jsonify(result), 200


   @app.route('/health/ready', methods=['GET'])
   @limiter.exempt
   def health_ready():
       """Kubernetes readiness probe - can accept traffic?"""
       result = readiness_check()
       # Return 503 if any check failed
       if result.get("status") != "ready":
           return jsonify(result), 503
       return jsonify(result), 200
   ```
