   - Create `create_limiter(app)` function:
     ```python
     def create_limiter(app):
         """Create and configure Flask-Limiter instance.

         Uses in-memory storage by default (single process dev).
         For production with multiple workers, set RATELIMIT_STORAGE_URI to redis://host:port
         """
         storage_uri = os.getenv("RATELIMIT_STORAGE_URI", "memory://")

         limiter = Limiter(
             key_func=get_remote_address,
             app=app,
             default_limits=["200 per day", "50 per hour"],
             storage_uri=storage_uri,
             strategy="fixed-window",
             headers_enabled=True,  # Include X-RateLimit-* headers
             enabled=os.getenv("RATE_LIMIT_ENABLED", "true").lower() == "true"
         )

         logger.info("rate_limiter_configured", storage_uri=storage_uri)
         return limiter
     ```
   - Create `ip_whitelist_filter()` decorator function that returns True if request.remote_addr in RATE_LIMIT_WHITELIST
   - Log whitelist IPs at module load (info level)

Note: Do NOT use ProxyFix yet - that requires infrastructure knowledge about proxy layers. Can be added later if deployed behind reverse proxy.

   ```python
   def handle_rate_limit_exceeded(e):
       """
       Handle 429 rate limit exceeded errors.

       Flask-Limiter automatically includes Retry-After header in response.
       We format the body consistently using build_error_response().
       """
       logger.warning(
           "rate_limit_exceeded",
           limit=str(e.description) if hasattr(e, 'description') else 'unknown',
           client_ip=request.remote_addr,
           endpoint=request.endpoint
       )

       return build_error_response(
           error='Rate limit exceeded',
           message=f'Too many requests. Please retry later.',
           status_code=429,
           error_code='RATE_LIMIT_EXCEEDED'
       )
   ```
